
## 📌 Project Overview
This project is a simple rule-based chatbot developed using Python.
It interacts with users through text input and provides predefined
responses based on user messages.

## 🎯 Objective
The main objective is to create a basic chatbot that can understand
simple user messages and respond accordingly using Python
programming concepts.

## ✨ Features
- Greets users with Hello, Hi, or Hey.
- Responds to "How are you?"
- Introduces itself when asked its name.
- Explains its basic capabilities.
- Responds to thank-you messages.
- Ends the conversation when the user types Bye.
- Handles unknown messages.

## 📚 Python Concepts Used
- if-elif-else statements
- Functions
- While loops
- User input and output
- String methods
